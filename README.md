# McKenzie Cambridge Preparatory Academy — Website

A proof-of-concept marketing site for **McKenzie Cambridge Preparatory Academy**,
a new independent school in the planning stages.

> _Crescimus Discendo, Ducimus Intellectu_ — We grow by learning, we lead with knowledge.

The site introduces the school's vision and keeps prospective families informed as
plans develop. Real content is still being gathered, so anything not yet finalized
appears as a clearly marked `[placeholder]`.
